# TripleTen Web Project: Homeland

## Overview

The TripleTen Homeland project is part of the 6th sprint of the TripleTen bootcamp. It demonstrates the application of HTML and CSS skills to create a responsive website based on a design prototype provided in Figma.

## Features

- **Fully Responsive Design**: Ensures seamless usability across various devices and screen sizes.
- **Semantic HTML5**: Structured and meaningful HTML elements for better accessibility and maintainability.
- **Modern CSS Techniques**: Leveraged advanced CSS features, including:
  - Grid layout for structured section organization.
  - Flexbox for flexible element alignment.
  - Gradients and shadows for enhanced visual appeal.
- **Media Queries**: Implemented to adapt the layout dynamically to different screen sizes.
- **BEM Methodology**: Used for consistent file organization and readable code structure.
- **Optimized Performance**: Includes image compression and the use of relative units for scalability.
- **Deployed on GitHub Pages**: The project is live and accessible online.

## Deployment

The project is deployed using GitHub Pages and can be accessed here: [TripleTen Homeland Project](https://victoralfonsoulloa.github.io/web_project_homeland/).

## Design

The website layout and aesthetics were guided by a Figma prototype provided during the bootcamp. The design emphasizes usability, scalability, and clean visuals across multiple devices.

## Development Highlights

### Key Objectives:
- Develop a fully responsive website using HTML and CSS.
- Adapt the design to various screen sizes using media queries and breakpoints.

### Breakpoints:
- **320px to 544px**: Optimized for mobile devices.
- **544px to 1024px**: Designed for tablet screens.
- **1024px and above**: Tailored for desktop resolutions.

### Enhancements:
- Added hover effects for buttons and images for better interactivity.
- Ensured consistent behavior across intermediate screen resolutions.

## Lessons Learned

- Mastery of responsive web design principles using CSS Grid and Flexbox.
- Application of media queries to build device-agnostic layouts.
- Importance of maintaining semantic HTML for accessibility and SEO.
- Value of structured and modular CSS with BEM for scalable projects.
